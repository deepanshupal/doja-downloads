# Doja downloads

Doja is a tiny pixel cat (and friends) that lives on your Mac's desktop and chats with you. Free, private, no account.

**Get it at [doja.pet](https://www.doja.pet)** or grab the latest DMG from [Releases](https://github.com/DeepanshuPal/doja-downloads/releases/latest).

First launch: Doja isn't notarized by Apple, so open it once, then go to **System Settings → Privacy & Security** and click **Open Anyway**.

This repository only hosts release files.
