## Opening the apps for the first time

The apps aren't signed with paid certificates.

- **Mac (Doja or Clippy):** open the app once, then go to **System Settings → Privacy & Security** and click **Open Anyway**.
- **Windows (Clippy):** if SmartScreen appears, click **More info → Run anyway**.

Clippy is not affiliated with Microsoft.
